# 页面动画模式库

> 触发形式：**用按钮点击，不要用 setTimeout / 定时器**。
> 定时器会让演讲者无法控制节奏——演讲讲多久不知道，几秒后触发可能正好打断讲话。按钮让演讲者自己掌控「什么时候演示动画」。

## 触发形式分类

页面有两种动画触发方式，根据场景选一种：

### A. 页内独立按钮（参考 P5）
页面上放一个明显的 `.morph-btn`，点击切换状态。
适合：动画是这页的主要内容（如 P5 的冯诺依曼类比 ⇄ Agent 全景）。

### B. 右下角翻页箭头（参考 P15）
直接复用右下角的 `›` / `‹` 导航按钮触发动画。第一次箭头点击 = 触发聚焦动画；第二次才真正翻页。**页内不显示额外按钮**。
适合：动画只是这页的一个状态过渡、不是独立动作（如 P15「讲完三个打分器再展示定位图」）。这样不打断演讲节奏——讲完三个打分器，自然按下箭头翻页时，动画就发生了。

---

## 模式 · 按钮触发 + 状态切换

**适用**：页面有两种自然的展示状态——讲解 A 状态 → 点击 → 切换到 B 状态；再点击 → 回到 A。

**现有示例**：
- **P5**：冯诺依曼映射 ⇄ Agent 全景（A 形式——页内独立按钮）
- **P15**：三张打分器卡片 ⇄ 三类定位图（B 形式——复用翻页箭头）

---

### 实现模式（三件套）

#### 1. CSS — 两套状态 + transition 平滑过渡

```css
/* P15：箭头触发聚焦（初始：卡占满 100%，图收起 0） */
.p15-top{
  display:flex; gap:14px;
  align-items:stretch; margin-top:6px;
  height:260px;
}
.p15-cards{
  flex:1 1 100%;                                  /* 初始：占满 */
  display:grid; grid-template-columns:1fr 1fr 1fr; gap:10px;
  transition: flex 0.8s cubic-bezier(.4,0,.2,1);
}
.p15-chart{
  flex:0 0 0; min-width:0;                        /* 初始：完全收起 */
  background:var(--card-blue);
  border:1.5px dashed #b8c8e0;
  border-radius:6px;
  padding:14px 18px; overflow:hidden;
  opacity:0; transform:scale(0.96);
  transition: flex 0.8s cubic-bezier(.4,0,.2,1),
              opacity 0.5s ease 0.1s,
              transform 0.8s, background 0.5s, border-color 0.5s;
}

/* 聚焦态：加 .focused class 触发 */
.p15-top.focused .p15-cards{ flex:0 0 30%; }
.p15-top.focused .p15-chart{
  flex:1 1 70%; opacity:1; transform:scale(1);
  background:#fff;
  border:2px solid var(--blue); border-style:solid;
  box-shadow:0 4px 20px rgba(27,111,214,0.18);
  padding:14px 18px;
}
.p15-top.focused .p15-chart svg{
  transform:scale(1.05); transform-origin:center;
}

/* P15 专用：箭头触发，页内按钮隐藏 */
#slide-p15 .morph-btn{ display:none; }
```

**要点**：
- 用 `flex` 而不是 `width` 控制尺寸，`flex` 过渡更平滑
- 完全隐藏元素用 `flex: 0 0 0; opacity: 0; overflow: hidden`，避免布局跳变
- transition 加 `cubic-bezier(.4,0,.2,1)` 比 `ease` 更自然
- 不同属性用不同 delay（比如 padding 先动、opacity 晚 0.2s），形成节奏感

#### 3. JS — 状态切换 + 触发接入

##### B 形式（复用翻页箭头，参考 P15）—— **推荐用于状态过渡型动画**

```js
// P15：聚焦状态机
var p15Focused = false;
function p15FocusToggle(){
  var top = document.querySelector('.p15-top');
  if(!top) return;
  p15Focused = !p15Focused;
  top.classList.toggle('focused', p15Focused);
}
function p15Reset(){
  p15Focused = false;
  var top = document.querySelector('.p15-top');
  if(top) top.classList.remove('focused');
}

// 核心：把 go() 函数里加 P15 拦截
function go(d){
  var s = slides[current];
  // ... 其它 slide 的拦截逻辑 ...
  // P15：第一次 → 触发聚焦；第二次才翻页
  if(s && s.id==='slide-p15' && d>0 && !p15Focused){
    p15FocusToggle();
    return;                                     // 拦截，不翻页
  }
  current = Math.min(Math.max(current+d,0),total-1);
  render();
}

// 进入 P15 时强制重置（保证初始永远是「三卡占满」）
function render(){
  // ... 原有逻辑 ...
  var cur = slides[current];
  if(cur && cur.id==='slide-p15'){
    p15Reset();
  }
}
```

**要点**：
- 拦截逻辑必须放在 `go()` 函数的最前面，避免先翻页再聚焦
- `d>0 && !p15Focused` 双条件：只有「前进」+「当前未聚焦」时才拦截
- `render()` 里加 reset：保证从其它页回来时 P15 是干净初始态
- **不需要**再绑按钮 click（页内按钮已隐藏）

##### A 形式（页内独立按钮，参考 P5）

```js
var morphBtn = document.getElementById('morphBtn');
if(morphBtn) morphBtn.addEventListener('click', function(){ archMorph(archState==='map'); });
```

### A 形式 vs B 形式 · 怎么选

| 场景 | 推荐形式 | 理由 |
|------|----------|------|
| 动画是页面主要内容（前后对比、重排） | **A** | 醒目，让观众知道「可以点这个」 |
| 动画是讲解过程中的自然过渡 | **B** | 不打断节奏，讲完直接按箭头 |
| 演示中需要反复来回切换 | **A** | 独立按钮可来回点，箭头拦截只能前进 |
| 一次性推进（讲完就翻页） | **B** | 拦截式最省力，无需单独按钮 |

## 进阶 · FLIP 重排动画（P5 用了）

P5 是更复杂的版本——点击后元素位置和大小重新排列。FLIP 四步：

1. **First**：记录每个 `[data-id]` 元素当前 getBoundingClientRect
2. **Last**：修改 DOM（加 class 触发新布局）
3. **Invert**：用 transform `translate + scale` 把元素反向位移回原位置
4. **Play**：下一帧清掉 transform，加 transition，元素自然滑到新位置

```js
function archMorph(toPano){
  var items = Array.prototype.slice.call(stage.querySelectorAll('[data-id]'));
  function flip(mutate){
    var first = {};
    items.forEach(function(el){ first[el.dataset.id] = el.getBoundingClientRect(); });
    mutate();
    items.forEach(function(el){
      var f = first[el.dataset.id], l = el.getBoundingClientRect();
      var dx = f.left - l.left, dy = f.top - l.top;
      var sx = l.width ? f.width/l.width : 1, sy = l.height ? f.height/l.height : 1;
      el.style.transition = 'none';
      el.style.transformOrigin = 'top left';
      el.style.transform = 'translate('+dx+'px,'+dy+'px) scale('+sx+','+sy+')';
    });
    requestAnimationFrame(function(){ requestAnimationFrame(function(){
      items.forEach(function(el){
        el.style.transition = 'transform .6s cubic-bezier(.22,.8,.3,1)';
        el.style.transform = '';
      });
    });});
  }
  // ...
}
```
